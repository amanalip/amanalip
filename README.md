## Recent Open-Source Projects

### [PipeViz](https://github.com/amanalip/PipeViz)

PipeViz turns a Jenkinsfile into an interactive pipeline graph directly in the browser. It parses declarative pipelines, parallel branches, matrix configurations, nested stages, conditions, steps, and pipeline metadata without sending pipeline code to a backend.

I built it with React, TypeScript, Vite, React Flow, and CodeMirror. It includes source-linked diagnostics, matrix expansion, pipeline inspectors, PNG export, shareable links, light and dark themes, accessibility work, automated tests, and a GitHub Actions workflow that builds and deploys the application to GitHub Pages.

### [Code Explorer](https://github.com/amanalip/code-explorer)

Code Explorer is a browser-based Python learning platform for understanding what a program is doing while it runs. Learners can write or paste Python code, execute it locally in the browser, and study the recorded execution one step at a time.

The main Python workspace includes 134 programs together with execution tracing, variable and data-structure views, control-flow analysis, replay breakpoints, code coverage, loop inspection, input comparisons, trace bookmarks, automatic learning comments, and debugging tools.

A separate Data Structures and Algorithms workspace contains 535 reviewed and executable programs across 25 curriculum sections, with 18 learning views covering execution state, structure behaviour, algorithm context, complexity, comparisons, and input experiments.

### [cloudservs](https://github.com/amanalip/cloudservs)

cloudservs is a visual cloud learning platform built to teach a vendor-neutral concept first, then show how AWS, Microsoft Azure, and Google Cloud implement it.

The project uses Astro and Starlight and currently maintains a 93-lesson curriculum ledger across nine modules. The repository includes static full-text search with Pagefind, local lesson progress, knowledge checks, provider comparisons, ASCII and Mermaid diagrams, accessibility-focused interactions, Playwright regression testing, privacy validation, and automated GitHub Pages deployment tooling.

### [Termodoro](https://github.com/amanalip/Termodoro)

Termodoro is an offline terminal Pomodoro timer and task manager written in Rust with Ratatui and Crossterm. It combines configurable focus sessions with task management, productivity history, streak tracking, themes, desktop notifications, local persistence, and keyboard-driven navigation.

The project has a modular Rust architecture, automated testing, CI, local-first storage, and no application telemetry.

### [TermLeaf](https://github.com/amanalip/TermLeaf)

TermLeaf is a Rust terminal reader that I am actively developing. The project is designed around local TXT, Markdown, and reflowable EPUB reading with keyboard navigation, search, saved positions, bookmarks, highlights, notes, responsive layout, and terminal-friendly image handling.

The implementation uses Rust, Ratatui, and Crossterm. Current development includes bounded Markdown and EPUB handling, internal navigation, archive and XML safety controls, image decoding, terminal capability detection, and responsive table-of-contents behaviour.
